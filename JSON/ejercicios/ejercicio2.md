# Ejercicio 2 — Identificar los tipos de datos

## JSON de observación:
```json
{ 
  "nombre": "Carlos", 
  "edad": 30, 
  "esEstudiante": false, 
  "telefono": null 
}
```

## Solución: Tipos de datos correspondientes

1. **"Carlos"** → `String` (Cadena de texto, delimitada por comillas)
2. **30** → `Number` (Número entero o flotante)
3. **false** → `Boolean` (Valor lógico: verdadero o falso)
4. **null** → `Null` (Ausencia intencional de cualquier valor o valor vacío)

---
**Objetivo:** Distinguir correctamente entre los tipos de datos primordiales en JSON: *String*, *Number*, *Boolean* y *Null*.
